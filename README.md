# LockIn

The public homepage for LockIn, the iPhone app for finding tutors, organizing study groups, and planning study sessions.

[Visit the website](https://senseibluebear2.github.io/lockin/) · [App Store](https://apps.apple.com/us/app/lockin-ebc5ad/id6821438497) · [Support](https://lockin-support.web.app/) · [Privacy Policy](https://lockin-support.web.app/privacy.html)

This static site is published with GitHub Pages from the repository root on `main`. Open `index.html` locally to preview. The layout and colors live in `styles.css`, and `assets/` contains the LockIn icon and selected app screenshots. The site has no build step.
